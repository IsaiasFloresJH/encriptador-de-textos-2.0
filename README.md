# Encriptador de Textos 2.0 🚀

Encriptador de Textos 2.0 es una aplicación web moderna y visualmente atractiva que permite encriptar y desencriptar mensajes utilizando diferentes algoritmos. Ideal para aprender sobre cifrado básico y compartir mensajes de forma divertida y segura.

## ✨ Características

- **Interfaz tecnológica**: Diseño moderno con efecto glassmorphism y colores neón.
- **Contraste visual**: Fondo oscuro con degradado al rojo intenso para resaltar el icono principal.
- **Varios algoritmos**:
	- Básico (sustitución de vocales)
	- Reversa
	- Base64
	- César (+3)
	- ROT13
	- Binario
- **Botones útiles**: Copiar, limpiar y descargar el resultado como archivo de texto.
- **Mensajes claros**: Indicaciones y alertas para mejorar la experiencia de usuario.

## 🖥️ ¿Cómo usar?

1. Escribe o pega el texto que deseas encriptar o desencriptar.
2. Selecciona el algoritmo de cifrado en el menú desplegable.
3. Haz clic en "Encriptar" o "Desencriptar" según lo que necesites.
4. Usa los botones para copiar el resultado, limpiar los campos o descargar el texto cifrado.

## 📦 Tecnologías utilizadas

- HTML5
- CSS3 (glassmorphism, neón, responsive)
- JavaScript (algoritmos de cifrado y lógica de UI)
